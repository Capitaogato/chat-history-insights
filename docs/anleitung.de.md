# Dein KI-Bericht – so geht's

**Du brauchst:** einen Computer, deinen ChatGPT-Zugang und etwa 30 Minuten.

1. **Datei herunterladen:** `chat-history-insights.py`. Du musst sie nicht öffnen. Es ist eine normale Textdatei für ChatGPT.
2. **ChatGPT öffnen** und einen neuen Chat starten.
3. **Die Datei in das Chatfenster ziehen** und diesen Satz dazuschreiben:

   > **Erstelle meinen KI-Bericht mit der angehängten Datei.**

4. **Abschicken.** Ab jetzt führt dich ChatGPT Schritt für Schritt durch alles Weitere, auch durch den Export deiner Chats.

Den Bericht gibt es auf Deutsch oder Englisch. Sag ChatGPT einfach, welche Sprache du möchtest.
